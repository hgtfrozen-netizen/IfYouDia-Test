# If You Die — 2D Top-Down Prototype (Test Task)

2D top-down прототип на Unity 6 (Universal 2D), выполненный в рамках тестового задания.

## Реализованный функционал
- **Управление и 8-направленная анимация персонажа:** плавное перемещение на `WASD` / стрелки через `Rigidbody2D` (New Input System) и покадровая 2D-анимация для всех 8 направлений.
- **Камера с границами уровня:** плавное слежение за игроком с ограничением по размерам карты (`CameraFollow`).
- **Сортировка глубины по оси Y и коллизии:** динамический расчёт `sortingOrder` по координате `Y` (`YSort`), непроходимые препятствия и границы карты.
- **Интерактивные предметы и UI:** зона триггера у объектов, всплывающая подсказка взаимодействия (`[E] Взять`), подбор предметов по клавише `E` и счётчик прогресса (`Собрано: X / 3`).

## Управление
- **W / A / S / D** или **Стрелки** — перемещение персонажа (8 направлений)
- **E** — подобрать предмет рядом с персонажем

## Версия движка
- Unity 6 (6000.6)
